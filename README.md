## 🚀 Live Preview / How to Open

### Method 1: Direct Double Click
Double-click **`index.html`** in File Explorer to open directly in Chrome, Edge, Firefox, or any modern web browser.

### Method 2: Local HTTP Server (Recommended)
You can run a local development server using Python or Node.js:

```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```
Then open: `http://localhost:3000`

## 🌐 Publishing to GitHub Pages

1. Create a repository on GitHub named `portfolio` (or `<your-username>.github.io`).
2. Push your project files:
   ```bash
   git init
   git add .
   git commit -m "Bharathi P portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository, open **Settings** ➔ **Pages**.
4. Set source branch to `main` and root `/`, then save.
5. Your portfolio is live online! 🎉
